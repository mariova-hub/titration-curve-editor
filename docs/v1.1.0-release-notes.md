# Titration Curve Editor v1.1.0

## 概要

v1.1.0では、炭酸塩・両性種への対応を追加し、炭酸ナトリウムを塩酸で滴定する二段滴定曲線を作成できるようになりました。対応物質は12物質から14物質へ増え、従来と同じ画面から滴定曲線の計算、編集、SVG / PNG出力を行えます。

## 主な追加

### 対応物質

- 炭酸ナトリウム Na₂CO₃
- 炭酸水素ナトリウム NaHCO₃

物質選択画面には「塩・両性種」グループを追加し、両物質を重複なく選択できます。

### 対応する滴定

- Na₂CO₃ + HCl：第一・第二当量点を持つ二段滴定
- NaHCO₃ + HCl：HCO₃⁻からH₂CO₃*へ向かう酸滴定
- NaHCO₃ + NaOH：HCO₃⁻からCO₃²⁻へ向かう塩基滴定

Na₂CO₃ + HClでは、2つの当量点を曲線上の補助線として表示します。Adaptive Samplingも両方の当量点近傍を高密度に計算します。これらの曲線と当量点表示は、Live Preview、SVG、PNGのすべてで共通です。

## 計算モデル

- 炭酸塩が持ち込む炭酸成分を、既存のH₂CO₃* / HCO₃⁻ / CO₃²⁻平衡へ統合します。
- Na⁺など、平衡反応で変化しないionも電荷収支へ反映します。
- 当量点と特徴点のpHは、各体積において通常の平衡solverで評価します。
- 既存12物質の計算、描画、SVG / PNG出力契約を維持します。

## 制約

- 炭酸系は炭酸成分の総量を水相内に保存する閉鎖系モデルです。
- CO₂の気相への散逸、開放系の炭酸平衡、Henry則、気相、発泡・速度論的効果は扱いません。
- 複数の分析物質を混合した水溶液の滴定には対応していません。
