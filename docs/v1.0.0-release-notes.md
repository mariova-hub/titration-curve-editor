# Titration Curve Editor v1.0.0

## 概要

高校化学の試験問題・授業教材向けに理論滴定曲線を作成し、図版としてSVG / PNG出力できるWebアプリの初回正式リリースです。

酸・塩基・モル濃度・体積を入力すると、酸塩基平衡に基づく滴定曲線を自動計算します。日本語のブラウザUIから軸、目盛り、線、文字、図のサイズを調整でき、Microsoft Word等へ貼り付ける図版を作成できます。

## 主な機能

### 滴定曲線計算

- 一価・多価の酸塩基系に対応
- 酸へ塩基を滴下する場合と、塩基へ酸を滴下する場合の両方向に対応
- 多段階電離平衡と複数当量点を計算
- 25 ℃における物質収支・電荷収支・酸塩基平衡からpHを数値計算
- すべての当量点近傍を高密度化するAdaptive Sampling
- 対応12物質を組み合わせて滴定曲線を生成

### 図版編集

- 曲線・軸・補助線の線幅、線種、色
- X/Y軸の表示範囲
- 主目盛り・補助目盛りと目盛り間隔
- X/Y軸ごとの目盛り方向（外向き・内向き・両方向）
- X/Y軸ごとの原点`0`表示
- 水平・垂直グリッド
- 複数の当量点・特徴点の補助線とマーカー
- 軸ラベルの位置と軸からの距離
- Y軸ラベルの横書き・左90°・右90°
- 自由な図のサイズ、縦横比、縦横比固定
- 白背景・透明背景

### Typography / Word

- Word等と同じpt単位で文字サイズを指定
- 目盛り数値、軸ラベル、タイトルのfont sizeとfont-familyを独立設定
- Century、MS Gothic、MS PGothic、MS Mincho、MS PMincho、ゴシック体、明朝体、sans-serif、serif、任意font-familyに対応
- Word貼り付け向けの試験問題プリセット（320 × 240 px、4:3）
- 教材向けの大きな図版とグリッド・補助表示を設定する教材プリセット

SVGへフォントファイル自体は埋め込みません。指定フォントが利用環境にない場合は、font-family stackまたは閲覧環境の代替フォントへfallbackします。

### Export

- Live Previewと同じSVG文字列を保存するSVG Export
- SVGをsingle source of truthとしてrasterizeするPNG Export
- PNG出力倍率：1倍・2倍・4倍（2倍推奨）
- SVG設定を使用・白・透明のPNG背景

### Web / PWA

- GitHub Pagesのproject site配布に対応
- Windows / Macの主要ブラウザから利用可能な構成
- 対応ブラウザでPWAとしてインストール可能
- 一度正常に読み込んだ後は、オフラインで滴定計算と曲線再生成が可能
- オフラインでSVG / PNGを生成可能

## 対応物質

### 酸

- 塩酸 HCl
- 硝酸 HNO₃
- 硫酸 H₂SO₄
- 酢酸 CH₃COOH
- シュウ酸 H₂C₂O₄
- 炭酸 H₂CO₃
- リン酸 H₃PO₄

### 塩基

- 水酸化ナトリウム NaOH
- 水酸化カリウム KOH
- 水酸化カルシウム Ca(OH)₂
- 水酸化バリウム Ba(OH)₂
- アンモニア NH₃

## 計算上の前提

- 温度は25 ℃固定
- `Kw = 1.0 × 10^-14`
- 活量補正なし
- 多段階電離平衡に対応
- 一部のKa / Kbに、高校化学の試験問題・教材との整合を優先した高校教材用定数セットを採用

計算モデル、数値解法、定数、適用範囲の詳細は[酸塩基平衡・計算仕様](./calculation-spec.md)を参照してください。

## 利用方法

ブラウザから以下のURLを開くだけで利用できます。

https://mariova-hub.github.io/titration-curve-editor/

一般利用にはNode.jsやnpmは不要です。

対応ブラウザでは、ブラウザまたはOSの標準機能を使ってPWAとしてインストールでき、一度正常に読み込んだ後はオフラインでも基本機能を利用できます。
