# Titration Curve Editor v1.2.0

## 概要

v1.2.0では、混合分析溶液滴定への対応を追加しました。通常の1成分滴定は従来どおり使用でき、必要な場合だけ2成分目を追加できます。

正式対応ケースとして、炭酸ナトリウム（Na₂CO₃）と水酸化ナトリウム（NaOH）の混合水溶液を塩酸（HCl）で滴定し、2つの当量点を持つ理論滴定曲線を作成できます。曲線、当量点、Adaptive Sampling、Live Preview、SVG / PNG出力は既存機能と同じ画面・操作で利用できます。

## 主な追加

### 混合分析溶液の入力

- 初期状態は従来と同じ1成分入力
- 「分析物質を追加」を押した場合だけ2成分目を表示するprogressive disclosure UI
- 各成分について物質と濃度を入力し、2成分で1つの共通体積を使用
- 追加した2成分目は削除して1成分入力へ戻すことが可能

### 対応する混合滴定

- Na₂CO₃とNaOHの混合水溶液をHClで滴定
- carbonateの2段階の反応とstrong hydroxideの寄与から、2つの当量点を計算
- 各当量区間のcharacteristic pointも通常の平衡計算で評価
- 両当量点周辺をAdaptive Samplingで高密度に計算
- 自動表示範囲、2本の当量点補助線、マーカーを既存の図版設定へ反映

### Validationと出力

- 同じ分析物質の重複入力を明確なメッセージで案内
- 滴定前に分析物質どうしの中和が必要な組み合わせを非対応として案内
- 現在の反応段階モデルで一意に扱えない組み合わせを非対応として案内
- mixed analyte curveをLive Preview、SVG、PNGへ出力

## 計算モデル

- 複数成分の物質量を、共通体積を持つ分析溶液全体の組成として統合します。
- carbonate familyとstrong hydroxideが持つプロトン受容量から、累積的な当量境界を算出します。
- pHは、各滴下体積における物質収支、固定ionの電荷、酸塩基平衡、Kwを使い、既存の電荷収支solverで計算します。
- 当量点とcharacteristic pointのpHも近似値を直接代入せず、通常のsolverで評価します。
- 既存14物質と従来の1成分滴定の計算・描画・出力契約を維持します。

## 制約

- UIで入力できる分析物質は最大2成分です。
- 滴定液は単一成分で、複数成分の滴定液には対応しません。
- stock solutionの濃度と混合量から調製後体積を計算する機能はありません。
- 初期混合時に実質的な中和反応が必要な組み合わせには対応しません。
- 複数の酸塩基familyの反応段階を一意に揃えられない組み合わせには対応しません。
- 沈殿、錯形成、気体発生を伴う系は扱いません。
- 炭酸系は炭酸成分の総量を水相内に保存する閉鎖系モデルです。CO₂散逸、開放系炭酸平衡、Henry則、気相、速度論は扱いません。
