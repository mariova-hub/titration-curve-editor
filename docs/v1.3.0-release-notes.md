# Titration Curve Editor v1.3.0

## 概要

v1.3.0では、編集中の滴定条件と図版設定を`.tcurve`プロジェクトファイルとして保存し、後から開いて同じ条件から編集を再開できるようになりました。

`.tcurve`は編集再開用のプロジェクトファイルです。完成した図を他の文書や教材で利用するSVG / PNG出力とは用途を分けています。通常の1成分滴定と、v1.2で追加した最大2成分のmixed analyte滴定の両方を保存・復元できます。

## 主な追加

### `.tcurve`プロジェクトの保存と読込

- 「プロジェクトを保存」から、現在の編集状態を`.tcurve`ファイルとして保存
- 「プロジェクトを開く」から、保存したファイルを読み込んで編集を再開
- 通常ブラウザ、GitHub Pages、PWAで利用できる標準的なdownloadとfile inputを使用
- single-analyte projectでは、分析物質、濃度、体積、滴定液を復元
- mixed-analyte projectでは、2成分の順序、各濃度、共通体積、滴定液を復元

### 図版設定の復元

- 試験問題／教材presetと個別に調整したグラフ設定を保存
- 軸範囲、目盛り、グリッド、当量点・特徴点、タイトル・ラベル、図のサイズ、背景、Typographyを復元
- 読込後はUI controlとPreviewの両方を保存状態へ置き換え

### Validationと互換性

- JSONとして壊れたファイル、必要な内容が欠けたファイル、不正な数値や物質を含むファイルを安全に拒否
- 現在のアプリより新しい未対応schemaを明示的なメッセージで案内
- `.tcurve`初版はschema version 1を使用
- 保存元を示すapp version metadataを記録し、file formatのschema versionとは分離

## SVG / PNGとの違い

- `.tcurve`：滴定条件と図版設定を保存し、後から開いて再編集するためのプロジェクトファイル
- SVG / PNG：完成した滴定曲線をWord、試験問題、教材等で利用するための図版ファイル

SVGやPNGを`.tcurve`として開いたり、SVG / PNGそのものを再編集可能なプロジェクトへ変換したりする機能ではありません。既存のSVG / PNG出力は、`.tcurve`とは独立して引き続き利用できます。

## 計算とプロジェクトファイル

- `.tcurve`には、計算済みの曲線点、solver中間状態、diagnostics、SVG文字列、PNG binaryを保存しません。
- 読込時は、保存された滴定条件と編集設定からproduction calculationを再実行し、曲線とPreviewを再生成します。
- そのため、`.tcurve`はsolver内部状態のsnapshotではなく、編集可能な入力条件と図版設定の保存形式です。

## 制約

- `.tcurve`はv1.3.0で定義したschema version 1を使用します。
- 現在のアプリより新しい未対応schemaのファイルは開けません。
- UIで入力できるmixed analyteは従来どおり最大2成分で、滴定液は単一成分です。
- 初期混合時に実質的な中和反応が必要な組み合わせや、反応段階を一意に扱えない組み合わせには対応しません。
- 炭酸系はCO₂散逸を考慮しない閉鎖系モデルです。
- SVG / PNGファイルを再編集可能にする機能ではありません。
